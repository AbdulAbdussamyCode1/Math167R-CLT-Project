CLT Project 1: Standard Normal Distribution

Author

Abdulwahab Abdussamy

Overview

The Standard Normal distribution is our baseline case. Since the population is already normal, the CLT should work immediately — even at very small sample sizes. This gives us a reference point to compare all other distributions against.

Setup

Code 
set.seed(1278)
B <- 10000

# install.packages("moments") # run this once in console if needed

2. My Prediction

Since the population is already normal, I expect the sampling distribution of the mean to look normal at every sample size, even n = 1. This distribution should converge the fastest of all the ones we test.

3. Monte Carlo Simulation

Code 
n_values <- c(1, 2, 5, 10, 20, 30, 50, 100)

results <- data.frame(
  n                = n_values,
  simulated_mean   = NA,
  simulated_sd     = NA,
  theoretical_se   = NA,
  skewness         = NA,
  kurtosis         = NA
)

for (i in seq_along(n_values)) {
  n <- n_values[i]
  sample_means <- replicate(B, mean(rnorm(n, mean = 0, sd = 1)))
  
  results$simulated_mean[i]  <- mean(sample_means)
  results$simulated_sd[i]    <- sd(sample_means)
  results$theoretical_se[i]  <- 1 / sqrt(n)
  results$skewness[i]        <- skewness(sample_means)
  results$kurtosis[i]        <- kurtosis(sample_means)
}

7. Conclusion

The sampling distribution of the Standard Normal mean is approximately normal at every sample size tested, including n = 1. This is expected since we are sampling from a normal population — the mean of normal random variables is itself normal regardless of sample size.

My “normal enough” standard:
I will consider a sampling distribution normal enough when:

  • The histogram is visually bell-shaped and symmetric
  • The Q-Q plot points fall close to the reference line with no systematic curves
  • Skewness is between -0.5 and 0.5
  • Kurtosis is close to 3

Answer for Standard Normal:
\[\boxed{n = 1}\]

The CLT is not needed here — the population is already normal, so the sampling distribution is normal at any sample size.

8. What Surprised Me

Even at n = 1, the sampling distribution is perfectly normal. This makes sense mathematically but seeing it confirmed visually reinforces why the Standard Normal serves as the ideal baseline — it shows us what “perfect normality” looks like so we can compare it against the skewed and heavy-tailed distributions later.
